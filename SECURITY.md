# Security Policy

## Scope

This is a static website repository. Security reports may concern exposed credentials, unsafe redirects, dependency or workflow changes, domain configuration, or accidental publication of private material.

## Reporting

Do not publish credentials, recovery codes, private addresses, personal evidence, or exploit details in a public issue.

Until institutional email routing is tested, use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, open a minimal public issue asking the maintainers to establish a private route, without including sensitive details.

After activation, the general institutional route will be `contact@archivo21.org`.
